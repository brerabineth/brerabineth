# brerabin

security tooling. detection over prevention.

what lands here: working blue-team tooling — canary tripwires, forensic
triage, detection rules, lab simulators. every tool is tested end to end
before it is published. no threat theater, no slide decks.

- [hellhound](https://github.com/brerabineth/hellhound) — decoy tripwire that catches ransomware on first touch. go.
- [gravedigger](https://github.com/brerabineth/gravedigger) — first-hour forensic triage for unix hosts. rust.
- [coroner](https://github.com/brerabineth/coroner) — ransomware note triage in the browser. nothing uploaded. javascript.
- [breraos](https://github.com/brerabineth/breraos) — micro operating environment inside windows. rust + tauri.
- [morgue](https://github.com/brerabineth/morgue) — local triage for infostealer logs. nothing leaves the machine. python.
- [familiar](https://github.com/brerabineth/familiar) — audit the familiars your agent keeps. mcp config + tool auditor. typescript.
- [placebo](https://github.com/brerabineth/placebo) — the fake fix, dissected. static triage for paste-and-run commands. powershell.
- [husk](https://github.com/brerabineth/husk) — first-hour static triage for elf binaries. nothing executes. c.

no socials. no DMs. the work is the identity.
